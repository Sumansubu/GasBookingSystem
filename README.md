# GasBookingSystem

A gas booking and customer management web application with a Flask backend and static frontend pages.

## Project structure
- backend/: Flask application, database models, and API routes
- frontend/: HTML, CSS, and JavaScript assets for the user interfaces
- init_db.sql, init_db_sqlite.sql: database initialization scripts

## Getting started
1. Install Python dependencies from backend/requirements.txt
2. Run the Flask app from backend/app.py or backend/app_simple.py
3. Open the frontend pages from the frontend directory
